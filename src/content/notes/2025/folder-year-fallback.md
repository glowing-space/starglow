---
title: The note folder year is only a fallback
description: A note with an updated date set in frontmatter, filed under 2025.
tags: [notes]
updated: 2026-11-20
---

This note sets `updated` in its frontmatter, and that value wins over the date taken from git. It sits in the `2025` folder, which only decides the URL and serves as a fallback date when git has no history for the file.
